# Student Attendance Management System

A lightweight, fully responsive, client-side web application built with HTML5, JavaScript, and Tailwind CSS. This portal allows educational institutions to manage student records, list subjects, log attendance, and view real-time attendance percentage reports—all directly inside the browser.

---

## 🌟 Key Features

* **Instant Login**: Pure browser-based authentication—no backend node server required.
* **Interactive Dashboard**: View real-time metrics including Total Students, Present/Absent counts, Today's Rate, and recent logs.
* **Student Directory**: Add, search, filter, and delete student records.
* **Subject Management**: Categorize subjects by code, department, and semester.
* **Mark Attendance**: Generate class rosters on-the-fly and submit daily attendance for specific subjects.
* **Reports & Alerts**: View overall student attendance percentages with automated low-attendance warnings (<75%).

---

## 🚀 Getting Started

Since this project runs completely in the browser, setting it up takes seconds.

### Prerequisites
* Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
* An active internet connection (required to load Tailwind CSS via CDN).

### Quick Setup
1. **Save the File**: Save your single file code as `index.html`.
2. **Launch**: Double-click `index.html` to open it directly in your browser.
3. **Login**: Click **Sign In** on the login page (default pre-filled credentials: `admin` / `admin123`).
